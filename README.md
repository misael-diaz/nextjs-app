# FlowStyle - E-commerce Demo

A modern Next.js e-commerce application showcasing AI-assisted development and advanced filtering capabilities.

## Overview

This repository demonstrates the power of collaborative AI-assisted development in building a production-ready e-commerce application. Unlike traditional "vibe coding" approaches, this project showcases a methodical development process where:

- **Problem-solving through understanding**: Each issue is analyzed, discussed, and resolved through clear communication and technical reasoning
- **Iterative refinement**: Features are built incrementally with continuous feedback and improvement
- **Quality-focused development**: Code follows established patterns, maintains type safety, and prioritizes user experience
- **Real-world application**: The result is a fully functional e-commerce platform with advanced filtering, responsive design, and modern UX patterns

All code has been generated through AI assistance, but the development process emphasizes understanding the underlying problems and agreeing on solutions before implementation. This approach produces maintainable, scalable code that goes beyond simple code generation.

## Features

### Advanced Product Filtering
- **Color Filtering**: Filter products by color (Black, Navy, Red, Nude, Brown, Tan, White)
- **Material Filtering**: Filter by material type (Leather, Suede, Canvas, Mesh)
- **Size Filtering**: Filter by available sizes (6, 7, 8, 9, 10)
- **Brand Filtering**: Filter by brand (FlowStyle)
- **Price Range Filtering**: Filter by price ranges ($0-50, $50-100, $100-150, $150-200, $200+)
- **Clear All Filters**: Reset all filters with one click
- **Real-time Updates**: Filters update results instantly as you make selections

### Product Catalog
- Comprehensive product grid with detailed information
- Individual product detail pages
- Responsive design for mobile and desktop
- Shopping cart functionality
- Wishlist management

### User Experience
- Modern UI built with shadcn/ui components
- Mobile-first responsive design
- Intuitive navigation and filtering
- Clean, professional aesthetic

## Tech Stack

- **Framework**: Next.js 15 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **State Management**: React Context API
- **Package Manager**: pnpm

## Getting Started

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Open http://localhost:3000
```

## Project Structure

- `src/app/` - Next.js app router pages
- `src/components/` - Reusable React components
- `src/contexts/` - React context providers
- `src/hooks/` - Custom React hooks
- `src/lib/` - Utility functions
